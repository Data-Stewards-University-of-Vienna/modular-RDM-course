# Research Documentation 

## Objectives
Learners will be able to:
* create clear, comprehensive documentation for their data.
* name and describe different metadata formats.
* describe the purpose and benefits of versioning and select a versioning tool that fits their project.

Content 

    Difference between project level and data level documentation
    Planning your metadata before you start
    Philosophy of capturing metadata as you work
    Folder Structure READMEs
    Versioning
    Common Tools in Wetlabs
    Common Tools in Computation
    Common Tools in Fieldwork
    Common Tools in Survey Data
